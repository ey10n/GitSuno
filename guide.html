GitSuno

アプリへ戻る

はじめての方へ

GitSuno は、Suno で作った曲ごとに「元曲」「曲調」「状態」「ToDo」「メモ」「公開済みかどうか」を記録できるアプリです。
使い始めるまでの準備は 最初の1回だけ・15分ほど です。

データはどこに保存されるの?

あなたの記録は、あなた自身の GitHub アカウントの中の非公開の保管場所に保存されます。
アプリの作者を含め、あなた以外の人が見ることはできません。料金はかかりません。

準備するもの

  • GitHub のアカウント(無料)
    持っていない場合は github.com/signup で作成してください。メールアドレスがあれば作れます。
  • パソコンまたはスマホのブラウザ

スマホで準備する場合、GitHub の設定画面が見づらいときは、ブラウザの「デスクトップ用Webサイトを表示」に切り替えると操作しやすくなります(iPhone の Safari ではアドレスバーの「ぁあ」から選べます)。

  1. 記録の保管場所を作る

    GitHub では保管場所のことを「リポジトリ」と呼びます。

    1. GitHub にログインし、github.com/new を開きます。
    2. Repository name に gitsuno-data と入力します(好きな名前でもOK。あとで使うので覚えておいてください)。
    3. その下の公開範囲で Private(非公開)を選びます。
      ⚠ 必ず Private にしてください。Public だと誰でも見られる状態になります(その場合アプリは使えないようになっています)。
    4. Add a README file(または「Add README」)を オン にします。
      オフのままだと、アプリから書き込めません。
    5. いちばん下の緑のボタン Create repository を押します。

  2. アプリ用の「鍵」を作る

    アプリがあなたの保管場所に書き込むための鍵(「トークン」と呼びます)を作ります。
    この鍵は 手順1で作った保管場所だけ を開けられるように設定するので、万一なくしても他のものには影響しません。

    1. トークン作成ページ を開きます。
      メニューからたどる場合: 右上の自分のアイコン → Settings → 左メニューいちばん下の Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
    2. Token name に分かりやすい名前を入れます(例: GitSuno-iPhone、GitSuno-PC)。
    3. Expiration(有効期限)を選びます。例: 90 days。
      期限が来たら、同じ手順で作り直してアプリに入れ直します。
    4. Repository access で Only select repositories を選び、gitsuno-data だけを選びます。
    5. Permissions(または Repository permissions)で Contents を探し、Read and write にします。
      ほかの項目は触らなくてOKです(Metadata は自動で Read になります)。
    6. いちばん下の Generate token を押します。
    7. github_pat_ で始まる長い文字列が表示されるので、コピーボタンでコピーします。
      ⚠ この文字列は この画面でしか表示されません。また、他人に見せたり、メールやチャットに貼ったりしないでください。

  3. アプリに設定する

    1. GitSuno を開き、右上の 設定 を押します(初回は自動で開きます)。
    2. 次のように入力します。
      データ用リポジトリの所有者あなたの GitHub のユーザー名
      データ用リポジトリ名gitsuno-data(手順1で付けた名前)
      ブランチ / ファイルパスそのままでOK
      アクセストークン手順2でコピーした文字列を貼り付け
    3. 自分専用の端末なら この端末にトークンを記憶する をオンにします。
      家族や職場などの共用端末ではオフにしてください(タブを閉じると消えます)。
    4. 保存して接続 を押し、画面上部に「データ未作成」または「読み込み完了」と出れば準備完了です 🎉

使い方

  1. Suno で曲の「…」→「共有」からリンクをコピーします。
  2. GitSuno の入力欄に貼り付けて 追加 を押します。
  3. 曲名をタップすると詳細が開き、元曲・曲調・状態・ToDo・メモなどを記入できます。

保存ボタンはありません。 入力すると約1.5秒後に自動で保存され、画面上部に「保存済み」と表示されます。

スマホでアプリのように使う

iPhone の Safari なら共有ボタン →「ホーム画面に追加」、Android の Chrome なら「⋮」→「ホーム画面に追加」で、アイコンから開けるようになります。

パソコンとスマホの両方で使う

  • それぞれの端末で手順2の鍵を作り(名前を「-PC」「-iPhone」などに分ける)、手順3で 同じリポジトリ名 を設定してください。同じ記録を見られます。
  • 別の端末で編集したあとは、画面上部の 再読込 を押すと最新の内容になります。

困ったときは

「接続失敗: 401」と出る
鍵が間違っているか、有効期限が切れています。手順2で作り直して、設定に入れ直してください。
「接続失敗: 404」と出る
ユーザー名・リポジトリ名の入力ミスか、鍵の対象に gitsuno-data が選ばれていません。
「保存失敗: 403」と出る
鍵の Contents が「Read and write」になっていません。手順2の5を確認して作り直してください。
「公開(public)です」と出る
保管場所が Public になっています。GitHub でリポジトリの Settings → いちばん下の Change visibility から Private に変更してください。
スマホをなくした / 鍵を見られたかもしれない
パソコンなど別の端末から GitHub の トークン一覧 を開き、その鍵を削除(Revoke / Delete)してください。記録そのものは消えません。
使うのをやめたい
設定画面の「トークンを削除」を押し、GitHub 上の鍵と gitsuno-data リポジトリを削除すれば完全に消えます。
